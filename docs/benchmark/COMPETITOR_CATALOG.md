## License boundaries

- BleachBit GPL-3.0-or-later includes cleaner definitions. Review the license before importing rules.
- Cryptomator desktop, mobile, Hub and cryptographic components have different licensing scopes.
- Bitwarden client GPL and Bitwarden License directories require separate review.
- VeraCrypt has its own TrueCrypt-derived terms. It is not a blanket permissive-license source.
- KeePassXC COPYING lists multiple component licenses.
- 7-Zip combines LGPL, BSD and specified unRAR restrictions.
- ShredOS includes separately licensed packages. Its distribution license does not replace package notices.
- HWiNFO embedding requires explicit licensor approval. This task did not obtain that approval.
- A free download does not establish business-use, bundling or source redistribution permission.
