## 실제 보호 범위
DPAPI 시험 앵커는 금고 밖에 존재한다. 공격자는 금고 파일만 과거 상태로 교체할 수 있다고 제한한다.
앵커가 최신 상태로 유지되면 Recovery Store와 전체 금고 재생을 거부한다.
이 제한은 같은 SID의 악성 코드에 대한 보호 경계가 아니다.
같은 SID의 코드는 DPAPI 데이터에 접근할 수 있다. 관리자도 로컬 상태 전체를 되돌릴 수 있다.
금고와 앵커를 함께 되돌리는 시험은 실제로 승인됐다. 해당 위협 모델은 UNSUPPORTED다.
시험 도구 exit 0은 시험 실행 완료다. 재생 방어 전체 PASS를 의미하지 않는다.

| 공격자 또는 상황 | 판정 | 근거 |
|---|---|---|
| 금고만 교체, 앵커 유지 | PASS, 제한된 모델 | 슬롯·전체 금고 재생 차단 |
| 동일 SID 악성 코드 | BLOCKED, 생산 보호 미확보 | 앵커와 금고 동시 재생 승인 |
| 관리자 권한 | NOT TESTED, 보호 주장 없음 | TPM·외부 Witness 없음 |
| 정상 백업 복원 | PARTIAL | 과거 상태 차단 및 인증된 읽기 전용 바이트 확인 |
| Windows 재설치·장치 교체 | NOT TESTED | 실제 키 이전 및 승인 절차 미실행 |

SHA-256은 파일 연결 식별에 사용한다. 인증된 금고 세대 검사를 대체하지 않는다.
AuthenticButStale는 결합 값 불일치다. 정상 변경을 앵커에 기록하지 않은 경우도 포함한다.
이 값은 공격 발생을 확정하는 판정이 아니다.
