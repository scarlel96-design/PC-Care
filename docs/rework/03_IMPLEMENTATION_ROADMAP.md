# 단계별 구현 로드맵

1. **Phase 0 — 기준 확정:** 브랜치/소스/테스트·실행 경로 재구성, 위험 등록, 검증 매트릭스. 현재 문서로 시작한다.
2. **Phase 1 — 데이터 손실·업데이트 긴급 방어:** 실제 ZIP 바이트 검증, 경로·항목·크기 제한, 검증된 목록만 스테이징. 회귀 fixture와 롤백 증거. 원자적 설치/서명된 메타데이터는 후속 게이트.
3. **Phase 2 — 신뢰와 데이터 경계:** 검증/무서명 허용/미검증/실패 분리, AV3 게이트·앱 라우팅 일치, 금고 데이터 이관·복구 충돌, 보안 삭제 파일 ID·하드링크·리파스 방어.
4. **Phase 3 — 기능·성능:** 시스템 케어 규칙별 골든 데이터와 오탐 예산, 병렬 작업 제한, 취소/재개, 전후 측정. 과장된 점수나 절대적 삭제 보증 제거.
5. **Phase 4 — UI/UX:** 공통 디자인 토큰·내비게이션·진행 상태, 접근성, 모션 축소, 설치기/앱 일관성. 화면 크기/DPI별 실사용 검증.
6. **Phase 5 — 배포:** 클린 빌드, 설치/업데이트/롤백 E2E, 서명·무서명 표시 분기, 패키지 해시/아티팩트 일치, 검토 후 릴리스.

각 단계는 구현·자동 테스트·실제 운영·독립 검증을 별도로 기록하고, 미달이면 다음 단계의 완료로 표시하지 않는다.
