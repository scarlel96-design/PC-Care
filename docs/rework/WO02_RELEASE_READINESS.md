# WO-02 릴리스 준비 판정

**NO-GO**. 이 브랜치는 보안 수정 검토용이며 `main` 병합과 공식 릴리스를 진행하지 않는다.

생산 업데이트 필수 조건 중 발행자 인증, 보호 스테이징, 허용 목록 기반 관리자 권한 적용 보조 실행 파일, 적용 저널/백업, 실패 후 복원, 설치 및 재시작 E2E가 충족되지 않았다. 현재 앱 내 적용은 차단되어 비신뢰 패키지를 설치하지 않는다.

AV3는 생산 Writer/저널/마이그레이션을 닫고 현재 상태를 ReadOnlyValidated로 표시한다. 실제 사용자 금고 포맷의 독립 감사·장치 내구성·생산 앵커·암호 구현 검증이 필요하다. 런타임 서명 상태는 분리했으나 공식 발행자 핀은 없다.

Windows CI는 빌드, 전체 테스트, 보안 회귀, TRX·환경·커밋 증거를 수집한다. 최초 원격 실행 결과는 별도로 확인해야 한다. 정상 앱 빌드는 설치/업데이트 E2E 승인과 다르다.
