# 디자인 시스템 명세 초안

방향: macOS의 여백과 계층, One UI의 손쉬운 도달성, Windows 11의 플랫폼 친화성을 혼합한다. 실제 구현은 PC-Care 토큰으로 통일하고 특정 상용 제품의 화면을 복제하지 않는다.

| 토큰 | 기준 |
|---|---|
| 간격 | 4px 기본 단위, 카드 내부 16~24px |
| 모서리 | 컨트롤 8px, 카드 12~16px |
| 타입 | Windows 시스템 폰트, 본문 14~16px, 제목 20~28px |
| 색 | 중립 표면 + 단일 파랑 강조, 상태는 색과 텍스트/아이콘 병행 |
| 폭 | 콘텐츠 최대 폭·반응형 1/2열, 최소 창 폭에서 수평 오버플로 금지 |

모든 상태는 기본/호버/포커스/비활성/진행/성공/실패를 명시한다. 파란 카드의 글자는 대비 계산 후 흰색 또는 충분히 밝은 중립색을 사용한다. 보안 금고/삭제 아이콘은 기능을 나타내는 벡터 아이콘으로 통일한다. 결과 목록은 심각도·범주·영향·선택 상태·복구 가능 여부를 한 행에서 읽게 한다. 설치기와 앱은 같은 색/타입/진행 문구를 공유한다.

검증: 100/125/150/200% DPI, 최소 창, 키보드 탭 순서, 스크린리더 이름, 고대비/다크·라이트, 번역 길이. [Microsoft 접근성 가이드](https://learn.microsoft.com/en-us/windows/apps/develop/accessibility)를 기준으로 삼는다.

## 구체 컴포넌트

- `AppShell`: 좌측 내비게이션은 홈·시스템 케어·통합 점검·보안·기록 및 복구·설정 6개 1차 목적지로 정리하고, 고급/진단 화면은 해당 페이지 안에서 접근한다. 현재 다수 XAML 페이지의 실제 사용 여부는 내비게이션 호출 그래프 검증 전까지 미확인이다.
- `HeroAction`: 상태 점수와 1개 기본 동작을 제공한다. 스캔 후 바로 복구되는 동작에는 예상 변경 수와 취소/복구 진입점을 명시한다.
- `FindingRow`: 선택 체크, 범주 아이콘, 제목, 근거 요약, 위험/복구 배지, 펼치기 상세를 고정 순서로 둔다. 전체 선택은 현재 필터와 전체 결과의 범위를 분명히 보여준다.
- `ProgressJourney`: 현재 단계, 완료 단계, 전체 퍼센트, 취소/재시도/대기 이유를 한 화면에서 표시한다. 수치와 결과는 같은 작업 ID를 유지한다.
- `SecurityActionCard`: 보안 금고/삭제 각각 고유 아이콘, 설명, 안전한 기본 버튼, 영향 범위를 표시한다. 밝은 파랑 위 어두운 본문을 금지한다.
- `ResultReceipt`: 완료/부분 완료/실패, 처리 수, 보류 수, 생성된 보고서, 복구 링크를 제공한다.

## 초기 시각 토큰

| 이름 | Light | Dark | 용도 |
|---|---|---|---|
| `surface.canvas` | `#F5F7FB` | `#10141C` | 창 배경 |
| `surface.card` | `#FFFFFF` | `#1B2230` | 카드 |
| `text.primary` | `#172235` | `#F3F6FC` | 본문/제목 |
| `text.secondary` | `#526079` | `#AAB6CA` | 부가 정보 |
| `accent.primary` | `#2364D8` | `#78A9FF` | 기본 동작/포커스 |
| `state.error` | `#B42336` | `#FF8A93` | 실패 |
| `state.success` | `#087B53` | `#55D7A1` | 완료 |

타입은 제목 28/34px·Semibold, 섹션 20/28px·Semibold, 본문 15/22px·Regular, 보조 13/18px·Regular를 시작값으로 한다. 토큰은 배포 전 실제 대비 계산과 Windows 고대비에서 재조정한다.

## 화면별 상호작용

홈은 상태→이유→다음 조치 3단계로 읽히고, 시스템 케어는 검사 전 범위 선택→진행→결과 검토→정리→영수증으로 흐른다. 통합 점검은 위험도가 높은 조치를 자동으로 묶지 않고 명시적으로 선택하게 한다. 금고는 폴더 트리와 파일 목록, 다중 선택, 열기/꺼내기 결과를 동일한 구조로 제공한다. 삭제는 대상 검토·확인·진행·증거 영수증을 별도로 제공한다. 업데이트는 발견→수정 사항→다운로드·검증→적용→재시작 완료 상태를 한 화면에서 이어 보여준다.
