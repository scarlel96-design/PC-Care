# 보안 기능 성숙도 점수 게이트

## 목적

보안 삭제와 장치 PURGE의 점수는 기능 수나 UI 완성도가 아니라, 검증 가능한 보안 통제와 운영 증거로만 계산한다. 이 규칙은 2026-07-30부터 다음 보안 빌드의 완료 게이트다.

## 축별 산식과 완료 정의

이전의 가중 종합식은 추세 확인에만 남긴다.

`참고 종합 신뢰도 = (구현 × 0.30) + (자동화 × 0.30) + (실제 운영 × 0.20) + (독립 검증 × 0.20)`

2026-08-09부터 이 저장소의 **70% 완료**는 참고 종합값이 아니라 아래 네 축이 각각 70 이상인 경우만 뜻한다. 하나라도 70 미만이면 해당 기능은 70% 미도달이다.

| 독립 축 | 70%에 포함하는 증거 | 절대 포함하지 않는 것 |
|---|---|---|
| 구현 | fail-closed 설계, 위협 모델, 경계 조건 코드, 사용자 고지와 감사 경로 | 코드량, 버튼 수, 미검증 설계 문서 |
| 자동화 | 재현 가능한 단위·통합·공격 회귀, 결과·해시가 남는 실행 게이트, 실패 시 fail-closed 검사 | 단순 빌드 성공, 수동으로 적은 통과 표기 |
| 실제 운영 | 격리된 실매체 시험, 재부팅·전원 중단·시간초과·잠금 실패 시나리오, 장치 원시 상태 로그 | 모의 전송 계층 테스트, 개발 PC의 일반 사용 로그 |
| 독립 검증 | 소스와 실행 증적을 받은 제3자 재현, 독립된 실매체/복구 시도 결과 또는 인증 기관 결과 | 개발자 본인의 재실행, 공급사 마케팅 문구 |

## 절대 규칙

1. 60% 또는 70%는 관련 축을 모두 다시 계산해 통과한 경우에만 선언한다. 2026-08-09 이후의 70%는 네 축 각각 70 이상을 요구한다.
2. 하드 차단 항목이 하나라도 있으면 점수와 무관하게 완료가 아니다. 예: 일반 Windows에서 PURGE 실행 가능, 보호 경로 삭제 가능, 지원하지 않는 매체에 장치 명령 전송, SSD 파일 Clear를 물리 삭제로 표기.
3. 자동 테스트는 독립 검증 점수를 대체하지 않는다.
4. 테스트 시간 초과는 통과가 아니다. 빠른 테스트와 장기 보안 시험을 분리하고 각 결과를 남긴다.
5. 컨트롤러 완료·감사 파일·보고서는 복구 불가 보증이 아니다. 증적의 범위와 한계를 함께 표시한다.

## 수치 게이트

| 목표 | 구현 | 자동화 | 실제 운영 | 독립 검증 | 추가 조건 |
|---|---:|---:|---:|---:|---|
| 내부 60% | 75 | 70 | 40 | 35 | 해당 기능의 P0 하드 차단 0건, 변경 항목 회귀·공격 시험 통과, 증적 해시 검증 가능 |
| 엄격한 70% | 70 | 70 | 70 | 70 | 격리된 실매체 매트릭스, 실패·중단 시나리오, 독립 재현 또는 외부 시험 증거가 모두 기능별로 존재 |
| 전문/인증 주장 | 별도 | 별도 | 별도 | 별도 | 해당 인증 기관 또는 독립 시험의 명시적 결과가 있어야 함 |

실제 운영 또는 독립 검증에서 증거가 전혀 없으면 해당 축은 0점으로 기록한다. 증거 수집용 코드나 실행 스크립트가 존재하는 사실만으로 실제 운영·독립 검증 점수를 올리지 않는다.

## 기능별 하드 차단

### 보안 삭제

- 폴더/파일 Dry Run 뒤 대상 구조·식별 변화가 있으면 삭제 전 중단해야 한다.
- 재분석 지점, 하드링크, 잠긴 파일, 접근 불가 하위 항목은 안전하게 차단해야 한다.
- SSD/NVMe 파일 삭제는 언제나 `Clear`로만 표기한다.
- VSS·백업·클라우드 사본은 자동 완전 삭제로 주장하지 않는다.

### 장치 PURGE

- 일반 Windows, 부팅/시스템 디스크, 지원되지 않는 버스·방식은 명령 전송 전에 차단해야 한다.
- WinPE, 대상 지문 재확인, 최신 읽기 전용 NVMe 증적 교차검증, 일회용 승인, 최종 확인, 볼륨 잠금이 모두 필요하다.
- 명령 전·후 상태와 결과는 검증 가능한 실행 증적으로 남겨야 한다.
- 실제 장치 완료 상태는 독립적인 복구 불가 보증으로 표기하지 않는다.

## 현재 증거 기록

- 2026-07-30: 폴더 구조 지문·실행 직전 재검증·파일별 재확인을 보안 삭제 경로에 추가했다.
- 2026-07-30: 장치 PURGE에 명령 전/후 로컬 변조 감지 실행 증적을 추가했다.
- 2026-08-09: 보안 삭제의 다중 대상 Dry Run은 스냅샷 생성 실패 대상을 개별 차단한다. 재분석 지점 회귀도 일반 대상 계획을 중단시키지 않고 차단 결과로 남긴다.
- `scripts/diagnostics/run-security-readiness-gate.ps1`는 자동 테스트, 환경 메타데이터, 임의 제공 증거 파일의 SHA-256을 하나의 실행 묶음으로 기록한다. 이 스크립트는 기본적으로 파괴 명령을 수행하지 않으며, 제공된 증거를 독립 검증으로 자동 승인하지 않는다.
- 점수 변경은 전체 회귀, 공격 시험, 실장비 검증 결과, 독립 재현 결과가 모인 최종 재계산 단계에서만 허용한다.
