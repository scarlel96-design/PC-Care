# WO-02 보안 검증

판정: **PARTIAL**.

업데이트: 합성 v1 ZIP 검사는 정상 콘텐츠를 `PUBLISHER-UNVERIFIED`로 표시하고 설치를 금지한다. 실제 바이트 변조, 경로 순회, 선언되지 않은 추가 파일, 중복 파일, 예약 이름 거부는 `tests/UpdateInspectorProbe`가 검사한다. 발행자 서명이 없어 관리자 권한 적용은 실행하지 않았다.

AV3: 생산 Writer·Journal·Migration 게이트를 코드에서 닫았다. `Av3PhaseGateTests`와 `Av3PhaseBTests`의 5개 Skip을 해제했다. 실사용 금고 접근과 자동 마이그레이션은 수행하지 않았다.

시스템 케어: 이동 전 JSON 저널을 원자적으로 기록하고, 격리본의 길이와 SHA-256을 검사한 뒤 복원한다. 원본 경로에 새 파일이 생기면 덮어쓰지 않는다. 이동 후 완료 기록 전 종료와 변조된 격리본을 합성 테스트에 추가했다. 정전·복원 중 강제 종료·저널 자체 손상 후 전수 재구성은 별도 검증이 필요하다.

테스트 실행의 정확한 결과와 종료 코드는 `evidence/wo02/TEST_RESULT.txt`에 기록한다. 테스트 호스트 연결 실패는 테스트 실패 0개와 구별한다.
최종 전체 실행은 641 통과·0 실패·111 Skip이었다. 실패했던 중간 실행은 AV3 앵커 설계 상수와 테스트 기대값의 구형 생산 GO 주장, 공유 임시 폴더의 시간 제한을 드러냈고, 해당 코드를 교정한 뒤 격리된 임시 폴더로 다시 실행했다.
