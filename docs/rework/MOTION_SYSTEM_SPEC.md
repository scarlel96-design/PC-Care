# 모션 시스템 명세 초안

모션은 상태 변화를 설명하는 데만 사용한다. 버튼 100~150ms, 카드/패널 180~240ms, 페이지 전환 200~300ms를 초기 토큰으로 놓고 실측 후 조정한다. 진행률은 실제 작업 값으로 단조 증가해야 하고, 재검증/재시도 때는 단계 라벨을 바꿔 원인을 알린다. 영구 반복 반짝임은 목록의 데이터 갱신과 분리한다.

`Reduce motion`을 켜면 이동·확대 전환을 즉시 또는 짧은 페이드로 축소한다. 대용량 목록은 항목 전체를 재생성하지 않고 안정된 키로 갱신한다. 애니메이션은 구성 요소의 시각 상태만 변경하고 보안/삭제/설치 엔진의 완료 판정을 지연시키거나 대신하지 않는다.

검증은 저사양 환경의 프레임 시간, CPU 점유, 포커스 유지, 취소/재시작, 창 크기 변경에 대해 한다. [Microsoft 모션 가이드](https://learn.microsoft.com/en-us/windows/apps/design/motion/)와 [애니메이션 성능 가이드](https://learn.microsoft.com/en-us/windows/apps/develop/performance/optimize-animations-and-media)를 참조한다.

| 유형 | 시작값 | 사용처 | 대체/중단 조건 |
|---|---|---|---|
| 상태 페이드 | 120ms ease-out | 검사 상태·배지 전환 | 모션 축소 시 즉시 교체 |
| 패널 진입 | 220ms ease-out, 8px | 상세 펼치기 | 포커스 이동 전 종료 |
| 페이지 전환 | 260ms ease-in-out | 1차 내비게이션 | 창 크기 변경 시 즉시 확정 |
| 진행 막대 | 실제 진척 값까지 180ms | 스캔·업데이트 | 값 미확정이면 무한 막대와 단계 설명 |
| 성공 확인 | 160ms 1회 | 적용 영수증 | 반복 루프 금지 |

금고 파일 목록과 결과 목록은 diff 기반 데이터 갱신 후 변한 행만 강조한다. 화면을 다시 그릴 때 스크롤·체크·키보드 포커스를 유지해야 한다. 장시간 작업의 모션은 30/60fps 장치에서 프레임 손실, 취소 지연, 접근성 설정을 자동 캡처해 통과 기준을 정한다.
