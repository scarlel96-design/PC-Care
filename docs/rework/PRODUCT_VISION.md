# 제품 목표와 검증 언어

PC-Care는 상태를 설명하고, 사용자가 변경 범위를 이해한 뒤 복구 가능한 시스템 관리 작업을 실행하는 Windows 앱이다. 보안 금고와 보안 삭제는 별도의 데이터 보호 영역으로 다룬다. 홈은 현재 상태·권장 조치·최근 기록을 보여주고, 상세 화면은 근거·예상 효과·복구 가능성을 보여준다.

제품 문구는 `탐지`, `제안`, `실행`, `확인`을 구분한다. 속도 향상 수치와 복원 불가 문구는 독립 측정·매체별 확인이 없는 한 절대 보증으로 표시하지 않는다. 설치기와 업데이트는 동일한 단계 언어(확인→검증→적용→완료/복구)를 사용한다.

성공 기준은 기능 수가 아니라 재현 가능한 정확성이다: 오탐과 데이터 손실 0건 목표, 모든 변경의 결과 기록, 실패 시 식별 가능한 복구 지점, 키보드·고대비·DPI 사용성, 설치/업데이트의 원자성.
