# 통합 실행 계획

최초 게이트는 `01_RISK_REGISTER.md`의 치명 항목이며, 작업 단위마다 다음 산출물이 필요하다: 변경 전 해시, 독립 재현, 최소 패치, 경계/음성 케이스, 앱 빌드와 관련 테스트, 다른 복사본 롤백, 사용자 데이터 호환, 변경 후 위험 재평가. 중대한 검증 공백이 남으면 릴리스 관문을 통과하지 않는다.

우선 실행 순서: U-01/U-02 완료 확인→U-03 설치 원자성→U-04 발행자 인증→V-01 AV3 게이트·실제 라우팅→T-01 런타임 신뢰 상태→D-01/Q-01 파일 동일성·복구 충돌→C-01 성능·오탐 측정→UX-01 디자인/모션·설치기. 단계별 구체 설계는 각 감사/아키텍처 문서에 있다.

배포 조건: 클린 x64 빌드와 테스트, 설치/업데이트/재시작/롤백 실제 Windows 실행, 기존 금고 데이터 round-trip, 보안 삭제의 대상 경계 검증, 아티팩트 SHA-256 재검사, 릴리스 노트가 검증 범위와 일치. 이번 문서/패치는 Phase 0·1의 시작 결과이며 main 병합 또는 릴리스를 포함하지 않는다.
